# Как читать стратегический пакет

Этот пакет — работа на этапе исследования, стратегии и дизайна. Он **не означает**, что гипотезы уже доказаны или что нужно переходить к разработке.

Порядок:

1. `01-startup-master-plan.md` — стратегическая ставка, жизненный цикл, критерии жюри, первые 8 недель и go/no-go.
2. `02-competitor-landscape.md` — актуальные публичные конкуренты, ценовой ориентир и тесты, которые нужно пройти лично.
3. `03-research-and-design-brief.md` — сценарии интервью, карта пользовательского пути и бриф дизайн-прототипа.
4. `references/source/` — исходные материалы VectoRise, на которые опирается разбор.

Сайт и код в основном архиве — ранний демонстрационный черновик. Этот отдельный стратегический архив не содержит исходников сайта/приложения и удобен для обсуждения до решения о разработке.
