# VectoRise

VectoRise — веб-платформа раннего планирования поступления для учащихся 9–11 классов Казахстана и их родителей. Этот репозиторий содержит публичный сайт, интерактивный демо-путь ученика, продуктовую концепцию и схему базы данных Supabase.

## Быстрый запуск

Сайт статический: откройте `index.html` локально или опубликуйте содержимое папки `product` через GitHub Pages, Netlify или Vercel. Для локального просмотра можно запустить любой статический сервер из корня папки. Демо-диагностика работает без сервера и хранит тестовый прогресс в браузере.

## Включить Supabase

1. Создайте проект Supabase.
2. Выполните `database/schema.sql` в SQL Editor.
3. Публичный сайт пока является прототипом и не отправляет личные данные в базу. Перед подключением клиента добавьте URL и anon key через переменные окружения сборщика, авторизацию и проверку согласия родителя для пользователей младше 18 лет.

Подробности продукта, MVP и модели дохода: `docs/product-concept.md`. Сводка конкурентной среды с источниками: `docs/competitors.md`.

## Состав

- `index.html`, `styles.css`, `app.js` — адаптивный сайт и демонстрационный интерфейс.
- `database/schema.sql` — таблицы, ограничения, индексы и базовые политики доступа.
- `docs/` — продуктовая концепция, модель запуска, исследовательские ограничения и конкуренты.

## Перед публичным запуском

Обновите контакт и политику конфиденциальности, проверьте актуальность возможностей и дедлайнов, подключите серверную авторизацию, аналитику с согласием и процесс работы с данными несовершеннолетних. Предложенные тарифы являются гипотезами из исходных материалов проекта, а не подтвержденной готовой ценой.
